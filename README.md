# 魔女たちの共同研究 — ブラウザ試遊版

人間1人＋AI3人で8日間を遊ぶ、協力と対立のルール検証用プロトタイプ。Vue 3 / TypeScript / Vite / Pinia。サーバー、ログイン、チャットは不要です。

## 起動

Node.js 24系（検証環境24.22.0）、npmを使用します。

```sh
npm install
npm run dev
```

表示された `http://127.0.0.1:5173/` をPCブラウザで開いてください。配布用ビルドは `npm run build`、確認は `npm run preview`。`dist/` を直接file://で開く方式には対応しません。

## 遊び方

1. 名前・乱数seed・固有魔法・能力を選択。能力は各2以上、合計10です。
2. 毎日2巡、日替わり順で1手番1APの採集・研究・購買部を実行。取引・仮納品・模擬戦は0APです。公開決闘は1巡目に2APを使い、2巡目はスキップ。AIは人間の手番や取引・決闘まで自動進行します。
3. 第1巡の仮納品は1人1単位（素材・薬・能力ポイントを合算）、取消で回復。第2巡以降は上限なし。自分の0AP操作後に「手番終了」。2巡終了後、全員の最終納品確認を経て「公開フェーズ終了」。成功時のみ予約品を消費。3失敗で即全員敗北です。
4. 固有魔法 → 秘匿行動 → 秘匿決闘 → 夜結果 → HO判定 → 夜明けと進めます。未選択の夜行動は休息です。錬金は夜だけで、材料・レシピ条件の範囲で複数薬を追加・削除して一括確定できます。
5. 戦闘はHP20・最大5R。手と薬を同時確定し1D6。ためる中は無防備で攻撃が命中します。強化は次Rの攻撃・防御に加算して消費、連続不可。5R目のためるは強化を発揮できません。秘匿決闘は全勝敗で結果を確認してOKを押し、その後に勝者の報酬を処理します。持込薬は未使用分も戦闘終了時に消失します。
6. 8日目終了時、長期HO達成者が卒業。卒業者内の日次HO達成数 → FPで首席を決定。同率首席あり。FP順位と卒業資格は別です。

画面左は公開能力と本人のHO・所持品、中央は操作とイベント、右は公開履歴と本人への通知。「開発者モード」を明示的にオンにするとAI内部情報・seed・乱数・全状態・判定ログを表示します。

## 保存・再開

成立操作ごとにlocalStorageへ自動保存。「保存」「続きから」、JSONエクスポート／インポートにも対応。v0.2.1の保存先は `majoken-save-v2`、1つのブラウザ・オリジンにつき1スロットです。v0.1の保存領域を削除・上書きせず、旧版の読込・継続・変換・再生には対応しません。旧版読込はバージョン不一致を表示します。ブラウザのデータ消去前にJSON保存してください。v0.2.1と異なるルール版の保存は読込を拒否し、自動変換しません。読込時にはルール版と操作ログ再生結果を照合し、破損や改変を拒否します。ローカル試験用なのでJSONや開発者ツールには全員の秘密情報が含まれます。対人戦用の秘密保護を提供するものではありません。

## 検証

```sh
npm test
npm run build
npm run simulate
npx playwright install chromium
npm run test:e2e
```

`npm run simulate -- 任意のseed1 任意のseed2` でseedを追加指定できます。JSON/CSVは `docs/reports/` に出力。ブラウザテストはローカルサーバーとChromiumを起動します。`npm run format` はソース整形です。
