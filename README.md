# 魔女たちの共同研究 v2.0 ブラウザ試遊版

人間1人とAI3人で研究所の8日間を進める、ローカル動作のブラウザゲームです。

## 起動

Node.js 24を使います。

```sh
npm ci
npm run dev
```

起動時に表示されるURLをブラウザで開きます。

## 遊び方

1. 名前・乱数シード・固有魔法（予知または結界）を選び、火・水・風を各2〜5、合計9に配分します。
2. 毎日2巡、基本2AP。自分の手番で採集・研究・購買部・公開決闘を行います。取引・仮納品・イベント模擬戦は0AP。イベントの成否は公開行動の終了時に確定し、通算3失敗で全員敗北します。
3. 戦闘はHP12・最大5ラウンドです。火は風、風は水、水は火に有利です。双方のダメージを同時に反映し、残HPで決着します。公開決闘では上位薬を最大2個持ち込めます。模擬戦は上位薬なしで、勝利FPもありません。
4. 夜は固有魔法を使うかパスし、襲撃・呪詛・警戒・休息・偵察を選びます。予知の候補は発動者が選びます。錬金は別枠です。夜間決闘の勝利FPはありません。襲撃の報酬はランダムに1個強奪するか、翌日の行動制限をかけるかを選びます。制限を受けた魔女は採集か研究を選びます。課題判定と夜明けはまとめて進みます。
5. 研究所が存続すれば、第8日の終了時に長期HOで卒業を判定します。長期HOのFP比較には第8日の日次報酬を足す前のFPを使います。首席は卒業者の報酬加算後のFPで決まり、同点なら日次HO達成数、それも同じなら共同首席です。

## 保存と再開

操作を確定するたびに `majoken-save-rules-2.0.2` へ自動保存します。「続きから」で最後に保存できた地点へ戻れます。保存が失敗した場合は進行を止め、専用ダイアログから同じ結果を再保存します。

公開済みv2.0・v2.0.1のセーブは対応する「旧版の続きから」で再開でき、以降も当時のルールと元の保存枠を使います。「続きから」は保存のある最新のルール版を開きます。新規開始では修正版のルールを使います。これらのルール版でJSON保存と読込に対応します。開発者モードと保存データには全員の秘密情報が含まれます。

## 検証

```sh
npm test
npm run build
npm run simulate
npx playwright install chromium
npm run test:e2e
```

- `npm run simulate` はv2.0で自動試遊し、`docs/reports/` にJSONとCSVを出力します。シードは `npm run simulate -- シード名` で指定できます。
- `npm test -- tests/v20-runs.test.ts` で、8日間完走・通算3失敗での即時崩壊を固定操作列で再現できます。
- ブラウザテストは現行画面を対象にした `e2e/v20-*.spec.ts` を実行します。旧画面用のE2Eは履歴として残し、旧ルールの単体テストは `npm test` で引き続き実行します。
- GitHub ActionsはプッシュとPRで検証します。Pagesへの公開は手動承認のワークフローで行います。
