# 魔女たちの共同研究 — ブラウザ試遊版

人間1人＋AI3人で8日間を遊ぶ、協力と対立のルール検証用プロトタイプ。Vue 3 / TypeScript / Vite / Pinia。サーバー、ログイン、チャットは不要です。

## 起動

Node.js 24系（検証環境24.22.0）、npmを使用します。

```sh
npm install
npm run dev
```

表示された `http://127.0.0.1:5173/` をPCブラウザで開いてください。配布用ビルドは `npm run build`、確認は `npm run preview`。`dist/` を直接file://で開く方式には対応しません。

## 遊び方

1. 「ゲーム開始」から名前・乱数シード・固有魔法・能力を選択。能力は各2以上、合計10です。卒業課題を確認し、各日の今日の課題を確認して進みます。
2. 毎日2巡、日替わり順で1手番1APの採集・研究・購買部を実行。取引・仮納品・模擬戦は0APです。公開決闘は1AP、勝者に1FP。残りAPは次巡で使えます。AIは人間の手番や取引・決闘まで自動進行します。
3. 第1巡の仮納品は1人1単位（素材・薬・能力ポイントを合算）、取消で回復。第2巡は上限なし。自分の0AP操作後に「手番終了」。2巡終了時に納品・イベントを自動判定し、結果を「確認した」で確認。成功時のみ予約品を消費。3失敗で即全員敗北です。
4. 固有魔法 → 秘匿行動 → 秘匿決闘 → 夜結果 → 課題判定 → 夜明けと進めます。未選択の夜行動は休息です。錬金は夜だけで、材料・レシピ条件の範囲で複数薬を追加・削除して一括確定できます。
5. 戦闘はHP20・最大5R。手と薬を同時確定し1D6。ためる中は無防備で、攻撃判定値−3（最低1）のダメージを受けます。強化は次Rの攻撃・防御に加算して消費、連続不可。5R目のためるは選択不可です。秘匿決闘は全勝敗で結果を確認して「確認した」を押し、その後に勝者の報酬を処理します。持込薬は未使用分も戦闘終了時に消失します。
6. 8日目終了時、卒業課題達成者が卒業。卒業者のみ最終FPで順位・首席を決定。同点は同率、未卒業者は順位なしです。

公開行動と秘匿行動は別画面です。行動を選ぶと対象・素材・コストを確認でき、確定前はキャンセルできます。右側の共通メニュー「持ち物」「課題」で所持数・薬の効果・本人の課題と進捗を確認します。戦闘は対戦相手確認→行動選択→行動公開→判定結果の順に進みます。「開発者モード」を明示的にオンにするとAI内部情報・シード・乱数・全状態・判定ログを表示します。

v0.2.3のレビュー修正（錬金の全レシピ効果・予定消費数・残数、初日の薬納品除外）は [docs/review-v0.2.3.md](docs/review-v0.2.3.md) を参照してください。初回の変更・調査記録は [docs/v0.2.3.md](docs/v0.2.3.md) を参照してください。

## 保存・再開

成立操作ごとにlocalStorageへ自動保存。「保存」「続きから」、JSONエクスポート／インポートにも対応。v0.2.2／v0.2.3の保存先は `majoken-save-v2`、1つのブラウザ・オリジンにつき1スロットです。v0.1の保存領域を削除・上書きせず、旧版の読込・継続・変換・再生には対応しません。旧版読込はバージョン不一致を表示します。v0.2.3の表示位置は別キーとJSONの任意メタデータに保存し、v0.2.2およびレビュー修正前のゲーム状態も元のルール版で読み込めます。新規ゲームは `browser-0.2.3+decisions-6` で初日の薬納品を除外し、既存の `browser-0.2.2+decisions-5` セーブは最初に配られたイベントを保持して再生します。ブラウザのデータ消去前にJSON保存してください。この2種類以外のルール版の保存は読込を拒否し、自動変換しません。読込時にはルール版と操作ログ再生結果を照合し、破損や改変を拒否します。ローカル試験用なのでJSONや開発者ツールには全員の秘密情報が含まれます。対人戦用の秘密保護を提供するものではありません。

## 検証

```sh
npm test
npm run build
npm run simulate
npx playwright install chromium
npm run test:e2e
```

`npm run simulate -- 任意のseed1 任意のseed2` でseedを追加指定できます。JSON/CSVは `docs/reports/` に出力。ブラウザテストはローカルサーバーとChromiumを起動します。`npm run format` はソース整形です。

## GitHubと公開

対象リポジトリは `mayidazhu6-lab/majoken-browser-prototype`。v0.2は `feat/browser-v0.2` で作業し、レビュー承認後にmainへマージします。[接続・作業記録](docs/github.md)を参照してください。

CIはpush／PRでビルド・単体統合テスト・自動試遊・ブラウザテストを実行します。Pages公開は自動実行しません。公開承認後にリポジトリ変数と手動入力の両方を設定したときだけデプロイする構成です。公開URLはまだありません。

最新の変更・原因調査・残るバランス上の懸念は[改修記録](docs/v0.2.2.md)、検証結果は[テスト報告](docs/test-report.md)。確率・公開決闘効率の再測定は `node --import tsx scripts/verify-v022.ts`。
