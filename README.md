# 魔女たちの共同研究 — ブラウザ試遊版

人間1人＋AI3人で8日間を遊ぶ、協力と対立のルール検証用プロトタイプ。Vue 3 / TypeScript / Vite / Pinia。サーバー、ログイン、チャットは不要です。

## 起動

Node.js 24系（検証環境24.22.0）、npmを使用します。

```sh
npm install
npm run dev
```

表示された `http://127.0.0.1:5173/` をPCブラウザで開いてください。配布用ビルドは `npm run build`、確認は `npm run preview`。`dist/` を直接file://で開く方式には対応しません。

## 遊び方

1. 名前・乱数seed・固有魔法・能力を選択。能力は各2以上、合計10です。
2. 毎日2APで採集・研究・錬金・取引・公開決闘。納品予約とイベント模擬戦は0APです。AIは公開開始時に行動し、人間への取引／挑戦で待機します。必要なら「AIの行動を進める」で続きを実行します。
3. 納品の必要数や必須素材を確認して「公開フェーズ終了」。成功時のみ予約品を消費。3失敗で即全員敗北です。
4. 固有魔法 → 秘匿行動 → 秘匿決闘 → 夜結果 → HO判定 → 夜明けと進めます。未選択の夜行動は休息です。
5. 戦闘はHP20・最大5R。手と薬を同時確定し1D6。ためるは次Rに消費、連続不可。持込薬は未使用分も戦闘終了時に消失します。
6. 8日目終了時、長期HO達成者が卒業。卒業者内の日次HO達成数 → FPで首席を決定。同率首席あり。FP順位と卒業資格は別です。

画面左は公開能力と本人のHO・所持品、中央は操作とイベント、右は公開履歴と本人への通知。「開発者モード」を明示的にオンにするとAI内部情報・seed・乱数・全状態・判定ログを表示します。

## 保存・再開

成立操作ごとにlocalStorageへ自動保存。「保存」「続きから」、JSONエクスポート／インポートにも対応。1つのブラウザ・オリジンにつき1スロットです。ブラウザのデータ消去前にJSON保存してください。読込時にはルール版と操作ログ再生結果を照合し、破損や改変を拒否します。ローカル試験用なのでJSONや開発者ツールには全員の秘密情報が含まれます。対人戦用の秘密保護を提供するものではありません。

## 検証

```sh
npm test
npm run build
npm run simulate
npx playwright install chromium
npm run test:e2e
```

`npm run simulate -- 任意のseed1 任意のseed2` でseedを追加指定できます。JSON/CSVは `docs/reports/` に出力。ブラウザテストはローカルサーバーとChromiumを起動します。`npm run format` はソース整形です。

## GitHubと公開

希望名 `majoken-browser-prototype` でローカルGitを用意しています。この環境のGitHubコネクターは認証ユーザーの確認には対応しますが、リポジトリ作成機能を公開していません。GitHub CLIも未導入のため、リモート作成・pushは未実行です。[接続手順](docs/github.md)でPrivateリポジトリにpushできます。

CIはpush／PRでビルド・単体統合テスト・自動試遊・ブラウザテストを実行します。Pages公開は自動実行しません。公開承認後にリポジトリ変数と手動入力の両方を設定したときだけデプロイする構成です。公開URLはまだありません。
