# 公開行動・情報表示UIの改善

PR #14統合済みmain（05074ef34063cd9352c8c11846b6941e62529c59）を起点に、表示・操作案内だけを変更する。ルール版browser-2.0.4と保存形式は維持する。

## 画面の変更

- 公開行動の時間帯を午前・午後と表示する。手番・1AP行動の使用状況・残りAPを維持し、選択した行動と必要APを操作欄に表示する。手引きと保存済みログの表示も同じ用語にする。元のログ文字列は書き換えない。
- 協力イベントの既存カードを納品操作の直前へ移動する。既存eventProgressの値から、素材・薬・能力・行動回数の必要数、予約数、不足数を表示する。必須素材、対象素材、先着ルート、模擬戦条件も保持する。予約・撤回・消費の処理は変更しない。
- 取引の提供・要求を自分が渡す／相手から受け取る方向で表示する。自分の所持総数と提供可能数を分離し、提案直前に相手名と交換内容を確認できる。スマートフォンでは各数量欄にも方向を表示する。既存actionError（状態のコピーへのdispatch）を用いて提案不可の理由を表示する。取引の成立判断・AIの返答は変更しない。
- 既存の品物選択欄に素材／薬の記号、名称、選択可能数、使用・仮納品する数を表示する。能力の納品欄には現在値と納品可能点数を添える。
- 属性選択時に火→風、風→水、水→火の有利関係と補正を表示する。Lv・薬もダメージに影響する旨を添える。旧戦闘には攻撃・防御・ためる・幻惑の説明を表示し、固定の三すくみとして扱わない。
- 研究所の累積失敗数と崩壊までの残り失敗回数を表示する。公開決闘の報酬は既存publicDuelRewardとセーブのルール版を参照し、当日の報酬・新旧の適用期間・双方の勝者への適用を説明する。秘匿戦闘と区別する。
