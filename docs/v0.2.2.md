# v0.2.2 改修記録

2026-10-30。対象 `feat/browser-v0.2` / PR #1。現行ルール版は `browser-0.2.2+decisions-5`。v0.2.1に対するユーザーの明示的な変更指示を優先し、mainへのマージ・Pages公開はしない。

## 調査結果と修正

| 項目 | 原因・確認した事実 | 修正 |
| --- | --- | --- |
| 連続ためる | 幻惑後の実際の行動ではなく変更前の選択を `previous` に記録。幻惑の変更候補にも禁止されたためるが含まれた。式自体には複数回分の加算はなく、強化値は上書きだった | 実際の行動を基準に連続制限。幻惑・AI・UI共通で合法手を制限。第5Rのためるを拒否。UIの選択も次Rで更新 |
| 仮納品できない | 局面を再構成した範囲で、正当な納品を拒否するドメイン不具合は再現せず。手番外・第1巡上限・対象外・所持/予約・総数の制限をUIが説明しなかった | 対象品を種類別数量で選択。選択後はロジックの拒否理由を表示。第1巡取消で枠回復、第2巡追加、先着満杯もテスト |
| 襲撃不可 | UI、nightChoice、AI候補に連夜禁止が明記されていた | 3か所で撤去。確定済み・対象不正は従来どおり拒否し、確定済みの理由を表示 |
| 未卒業者の順位 | 全員のFP順位と、卒業者の日次HO優先の首席を別計算していた | 卒業者のみ最終FP順。日次HO数は順位に使わず、未卒業者rankはnull。同率は従来の競技順位（1,1,3）、同率首席あり |

幻惑の効果そのもの・当初選択を参照する戦術HOは維持する。変更候補を合法手に限定し、強化値は次Rの攻撃/防御で1回消費する。攻撃vsためる `max(1, 攻撃判定値 - 3)`、相互攻撃、完全防御・カウンター、HP20、1D6、最大5R、薬効果・持込資格は維持。

## 公開進行と決闘

- 日替わり順、2巡、通常1手番1AP、パス、0AP取引/予約は維持。
- 第2巡の最後の手番終了後に既存のresolveEventを自動実行。第3巡の最終納品確認・手動判定ボタンは廃止。予約変更は自分の通常手番の終了まで（1AP使用後も終了前なら可）。終了した魔女への追加確認手番は設けない。
- イベント成否・必要条件・最終納品・FP/消費/返却/失敗累計を中央表示し、OKまで後続操作を拒否。研究崩壊時も結果を確認できる。確認はFPを再付与しない。
- 公開決闘は挑戦者1AP、被挑戦者0AP。勝者だけFP+1、敗者・引分はFPなし。能力移転は撤去。第1巡実行後も第2巡で残りAPを使用可能。
- 公開決闘は人間不参加のAI同士も含めて結果→OK→元の公開手番へ復帰。FPは1度だけ付与。降参は従来の素材2/薬1個の譲渡だけ、FP・勝利実績なしで結果を確認する。
- AIは通常決闘を両巡の候補とし、1APで評価。従来どおり挑戦を受け、AIからの自発的な降参は実装しない。秘匿決闘の結果→OK→強奪/命令は維持。

## UI

納品・購買部・降参は種類別の所持数と数量で選び、個体IDは表示せず内部で解決する。錬金候補は解放条件と所持素材、現在の作成予定を差し引いて作成可能なものだけ。削除すると候補が復活し、追加不可なら明示する。確定済みレシピ一覧と個数、同日JSON同期は維持。

0AP取引の提案ボタンもAP残量で無効化せず、既存の取引ルールに合わせた。公開挑戦/戦闘中はイベントパネルを参照可能。秘匿中のイベント詳細非表示は維持。進行操作を履歴より上に移動。強制行動は折り返すflex配置にし、PC/狭幅で重なりを検証。日次結果はFP・Lv通知とHO判定を中心にし、同じ能力値の再掲を削除。未達成・未判定も表示する。

## 保存・テスト

保存形式2と `majoken-save-v2` を維持し、v0.1領域は変更しない。旧ルール版の保存は既存の厳密な版検証で拒否し、自動変換しない。結果確認待ちも操作ログから保存・再生可能。新しいイベント/降参の確認操作をログに含め、確認時の報酬再実行を防ぐ。

検証結果は [test-report.md](test-report.md)。全4既存seedは8日完走。崩壊のUI回帰は合法なパス・休息方針のcollapse-ui-298（7日目、取引返答後の自動判定）を使用する。ルール変更で局面が変わったブラウザfixtureは、合法な履歴を再生成して更新し、必要な勝敗・秘匿境界の検証は維持する。

## バランス検証と残る懸念

[verify-v022.ts](../scripts/verify-v022.ts) と [測定JSON](reports/v022-balance.json) に再現手順・条件を記録。

採集と同じ6択抽選を固定seedで60,000回実行。黒曜石9,977、結晶9,953、月光草10,184、星の砂9,933、精霊水9,929、夜露石10,024（16.55〜16.97%）。均等抽選に問題は見つからず確率は変更しない。結晶は研究と7レシピに使用され、夜露石には薬用途がないため、所持数の体感は消費先にも影響される。

同等能力AI同士100戦は43勝/43敗/14引分、挑戦者の直接FP/APは0.43。育成済み・攻撃特化対未育成、および同じ弱い相手への2巡連続挑戦は、今回のAI期待値方針・薬なしでは全戦引分だった。完全防御下で双方が防御を選び続ける局面があり、この標本では強者の連続FP獲得は確認できていない。これは人間の最適戦略や全能力配分の安全性の証明ではない。

1勝1FP/1AP（1日2回なら直接最大2FP）に加えてHO報酬が重なる場合がある。被挑戦者はAPなしで勝利FPを得る。イベント貢献は0AP納品で成功時1〜2FP、研究は直接FPなしで成長/HOに寄与するため単純な効率比較はできない。AIは降参を選ばないため、弱者の降参連鎖は今回のAI試験では評価できない。AIの防御継続・人間の反復挑戦・卒業条件への影響を有人再試遊で確認する。追加の計算式・FP・AI降参バランス変更は行っていない。
