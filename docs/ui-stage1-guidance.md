# 改修④ 第1段階：操作と情報整理

PR #16のP2・P3対応と修正前後の比較は[レビュー指摘対応](ui-stage1-review.md)を参照。以下のキャプチャ・検証件数は当初コミット663503a時点の記録。

最新main（PR #15統合済み、b50e8d3860ac41630869cea2e931b13106c5fb4b）を起点に、正式作業フォルダのfeature/ui-stage1-action-guidanceで実装。

## 実装内容

- 日数・時間帯・残りAP・名声を表示するコンパクトな固定ヘッダーを追加。APトークンと、その時間帯の1AP行動枠の使用状況を別に示す。残りAPがあっても現在行動できない理由を表示し、夜は公開行動用のAPと明記する。
- スクロール中もヘッダーを表示。戦闘の固定表示とは高さを連動させる。既存の画面切替スクロールを操作領域の先頭へ合わせ、キーボードでイベント操作を開いた後も見出しへフォーカスを移す。
- 研究所耐久をmax(0, 3−累積失敗数)の数値とゲージで表示。耐久1は「次に失敗すると崩壊」と警告し、累積失敗数と条件は展開して確認できる。自分のAP・FPと共有の耐久を分離する。
- PCはイベント・自分の課題を左、公開行動の操作を右へ配置。スマートフォンではイベントから操作へ続く1列と、2列の行動ボタンを使う。
- イベントの必要数・全員の予約数・不足数・必須素材・指定素材を、納品画面と共通のEventOverviewで表示。複合条件は条件ごとのゲージ、先着ルートは別条件として示し、条件充足と成功確定を区別する。
- 納品、模擬戦、対象の採集・研究への導線をイベント種別から表示。移動ではopenActionのみを呼び、模擬戦は0APの操作を選択して主ボタンを強調する。確定・AP消費・戦闘開始は従来の実行ボタンで行い、既存can/dispatchのガードを維持する。
- イベントの条件・報酬・予約内訳、公開行動の進め方、魔女の公開情報を折りたたむ。操作に必要な数値と、実行不可理由は隠さない。自分の今日の課題だけを短く表示する。
