# UI・画面遷移改善（2026-11-06）

PR #7統合済みmainを起点に、正式作業フォルダで `feature/ui-phase-summary` のみを作成。開始時の未コミット変更なし。worktree・別クローン・Pages更新なし。

- 仮納品の余分な `>` と未選択時の案内を除去。未選択時の無効化、選択・納品検証、エラー表示を維持。
- 購買部の重複見出しを除去。交換条件・1AP表示を維持。
- 決闘ボタンに16pxの間隔と44px以上の高さを設定。600px以下では縦配置。
- 秘匿行動確定時の独立した結果確認画面を省略。ドメインの行動確定・記録・公開範囲を維持。旧UIメタデータの秘匿行動結果も復元しない。
- 課題判定後は当日の夜明けで待ち、確定済みログ・日次HO履歴から本人向けまとめを表示。「次の日へ」で翌日へ進む。翌日のブリーフィングには前日のまとめを表示しない。

`advance.pauseAtDawn` は画面進行の待機指定。旧操作ログでこの指定がない場合は従来の進行を維持し、保存形式・ルール版・乱数・既存セーブの再生を変更しない。HO判定と夜間持ち物集計はhoで一度だけ実行し、dawnでの再開・翌日移行では再実行しない。

検証結果：Vitest 424件、Chromium E2E 23件、本番ビルド成功。4シードのシミュレーションは全て8日完走。PC 1440px・スマートフォン390pxのスクリーンショットを目視確認。夜行動確定、秘匿決闘の入力確定、報酬選択前後、当日のまとめ、翌日の各段階で再開を確認し、保存データの同一性・まとめの非再表示を検証。既存AP・属性Lv・研究プレビュー・シード・公開戦闘・旧セーブの回帰テストも成功。
