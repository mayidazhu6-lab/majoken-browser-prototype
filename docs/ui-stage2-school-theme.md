## 実装

### 昼夜テーマ

ゲームのphaseから表示だけを導出する。公開行動、朝の課題確認、イベント結果、公開戦闘は昼。magic／vote／night／duels／rewards／resultsは夜。ho／dawnは夜明けとして昼、終了画面とタイトルも昼。公開／秘匿の戦闘は既存の進行フェーズに従う。

`html[data-theme]`へ反映するため、bodyへTeleportするダイアログも同じ色になる。ゲーム状態・保存データ・表示管理の保存項目にテーマは追加しない。再開時も既存状態から導出する。

| 用途 | 昼 | 夜 |
|---|---|---|
| 背景 | #EFE9F5 | #201B31 |
| カード | #FFF9EF | #30283F |
| 本文 | #39263F | #F5EFF8 |
| 主ボタン | #70456F | #C9ADE8 |
| 主ボタン文字 | #FFF9EF | #2A1834 |

旧固定色を共通トークンへ置換し、丸角・細い二重枠・陰影・静かな光を統一。夜は薄い静止リングを背景に置く。色の補間中にコントラストが低下しないよう切替は即時。常時アニメーション・音声・外部画像・外部フォントは追加しない。

### 共通SVG

GameIconとiconCatalogに描画を集約。6素材は石／結晶／三日月葉／星の袋／雫入り瓶／真珠状の雫で識別し、精霊水と人魚の涙を形状でも分ける。

現行仕様の能力名は火・水・風で、戦闘属性と同じ炎／雫／風の渦を共用する。旧能力名には剣／盾／眼を使う。現行の薬9種は共通瓶と異なる紋章、従来薬のIDにも対応する紋章を用意する。採集候補、研究・能力説明、納品、取引、持ち物、錬金、戦闘・履歴で共用。OS標準selectのoptionは名称を維持し、隣接するプレビュー等で図柄を添える。

名前・所持数・消費数は維持し、アイコンだけに依存しない。通常のアイコンはaria-hidden、focusable=falseで装飾扱い。単独表示用のlabelを渡したときだけ画像として読み上げる。薬・アイテム・能力のIDや効果は変更しない。

### 属性相性図

火→風→水→火の三角図に共通アイコンと名称を配置。矢印は有利な側から相手へ向く。有利＋1／不利−1／同属性0を併記し、詳しい計算説明は展開式にする。選択した頂点と関係する辺を枠・太さ・破線でも強調する。

入れ子SVGのサイズを明示してスマートフォンでの拡大・重なりを防ぐ。AP・時間帯ヘッダーは固定を維持し、HPのスコアボードは通常スクロールにして図と操作を覆わないようにした。対戦中はヘッダーの重複する公開行動の長文理由を省き、APと行動枠の表示は維持する。

旧戦闘方式の攻撃・防御・ためる・幻惑の説明は残し、三角図と混同させない。元からUI読込対象外のセーブ版を新たに受け付ける変更は行わない。

### 第1段階の維持

固定ヘッダー、APと行動枠の区別、研究所耐久、イベント進捗と操作導線、模擬戦／通常決闘の排他的な確定、スマホ上部の行動導線、詳細展開、消費プレビューを維持する。色を同じゲーム状態で切り替えても行動欄の寸法が変わらないことも確認。
