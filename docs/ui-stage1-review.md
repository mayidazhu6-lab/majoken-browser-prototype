## P2：決闘種別の誤操作防止

既存の一時的なUI状態eventMockSelectedを利用し、選択中の種別の確定ボタンだけを表示する。模擬戦中には通常の公開決闘を確定できず、逆方向も明示的な「切り替える」操作を必要とする。イベント対象外・模擬戦完了後は模擬戦への切り替えを表示しない。

切り替えでは相手を未選択に戻し、選択中の品物・持ち込み・薬をクリアする。相手を選び直すまで確定ボタンは無効。キャンセル・他の行動へ移る際には、未選択値を他の画面へ持ち越さない。種別とAPを確認欄に明記し、模擬戦中は通常決闘のFP案内を隠す。切り替え操作は消費なし、確定時は通常決闘1AP／模擬戦0APであることも併記する。

変更は表示・選択状態だけで、切り替え時にdispatchしない。実行ボタンにも種別のUIガードを設け、既存can/dispatchによる実行条件・AP・戦闘・報酬・イベント判定は維持する。

## P3：スマートフォンの行動アクセス
