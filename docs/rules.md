# 実装済みゲームルール

現行：v0.2.2。[最新改修記録](v0.2.2.md) を優先し、[v0.2記録](v0.2.md) は変更前の履歴とする。

## 進行・勝敗

4席、人間1＋AI3、8日間。能力2/2/2＋配分4、素材3、長期HO1・日次HO1、FP0で開始。同日の日次HOと長期HOは各プール内で重複なし。次日の同種日次HOは可。

公開 → イベント判定 → 魔法（予知時は投票） → 秘匿行動 → 秘匿決闘／報酬 → 夜結果 → HO → 夜明け。公開AP2、日替わり順の2巡制。1巡につき1AP行動1回、パス可能。0AP行動後は明示的に手番終了。2巡終了で納品とイベントを自動判定し、結果をOKで確認。イベント3失敗で直ちに全員敗北し、その夜の処理・HO判定なし。8日を完走すると長期HO達成者だけ卒業。卒業者のみ最終FP順で順位・首席を判定。同点は同率、未卒業者は順位なし。卒業者0人なら卒業者なし。

## 公開行動

| 行動 | AP | 内容 |

| 採集 | 1 | 6素材を復元・等確率で基本2個 |
| 研究 | 1 | 攻撃＝黒曜石+結晶、防御＝月光草+星の砂、洞察＝精霊水+夜露石。各1消費、基本+1 |

| 魔女間取引 | 0 | 双方同意、成立・拒否・撤回すべて0AP。同じ相手へ1巡2申請、AIは1手番1申請。片側0可、双方0不可 |
| 公開決闘 | 1 | 被挑戦者0AP。勝者FP+1、敗者/引分0、能力移転なし。降参はアイテム譲渡のみ、双方FPなし |

素材：黒曜石・魔力結晶・月光草・星の砂・精霊水・夜露石。夜露石は洞察研究・任意素材納品に使用。旧5素材指定のレシピ・イベントへ代用不可。各アイテムにIDを持ち、予約中は使用・交換不可。第1巡の予約は1人1単位（素材・薬1個／能力1ポイントを合算）、取消で回復。第2巡は個人上限なし、必要総数の範囲で先着順。納品撤回可。成功時のみ消費、失敗時返却。超過納品・能力下限割れを拒否。

## イベント

全12種、重複なし。第1〜4日 Easy/Normal/Hard＝45/45/10、第5〜8日＝5/45/50。未使用カードのない難度を除き再正規化。詳細条件・報酬は `src/domain/events.ts` に定義。素材／能力の二択イベントは先に成立したルートだけ採用、非採用側を返却。最多寄付FP、指定素材、研究／採集回数、模擬戦複合条件を区別。有効貢献は1人1イベント最大1件で、FP報酬と別に記録。

## 秘匿行動・魔法・薬

攻撃・防御・洞察は独立に能力6でLv2、9でLv3。

- 襲撃：他者と秘匿決闘。連夜も選択可能。確定済みの夜行動は変更不可。
- 呪詛：翌公開最初のAP行動へ−Lv。重複時は最大だけ適用。購買部・決闘でも呪詛を消費するが成果減衰なし。0AP取引では消費しない。
- 警戒：襲撃を受けた戦闘初Rの防御判定+Lv。
- 休息：今夜決闘なし、または全勝なら翌日の全採集・研究へ+1/2/3。
- 夜錬金：複数レシピ・同種複数個を上限なく一括確定、0AP。素材・解放条件を全件検証し、他の秘匿行動とは排他。
- 偵察：対象が襲撃・警戒ならFP−1（下限0）、それ以外はアイテム1個確認。影渡り中は呪詛にもFP減点、確認数+2。

固有魔法は予知CD3、幻惑CD2、結界CD3、影渡りCD2、秘伝錬成CD2。第n日に使うと次回n+CD日。予知・秘伝は第8日不可。結界はその夜の襲撃・呪詛・偵察を遮断。予知は共有候補3枚への使用者匿名投票。秘伝は翌日の夜錬金まで特殊レシピ1種を使える。

日次HO達成FP+1。イベントと公開決闘のFP報酬を維持。最高到達FP5で未解放特殊薬1種をランダム解放、10で任意1種。一度だけで再ロックなし。薬の全レシピ・効果は `src/domain/items.ts`、補完理由は decisions.md。

## 戦闘

HP20・最大5R。双方が攻撃／防御／ためると薬の有無を同時選択し1D6。攻撃／防御判定は対応能力＋出目＋前Rため＋当該R薬。ためるは洞察＋出目を次Rへ1回分だけ保持し、翌R消費、連続不可。幻惑後の実際の行動で判定する。ため中は無防備。攻撃判定を防御値と比較せず、`max(1, 攻撃判定値 - 3)` のダメージを受ける。同値でも命中し、ためる側のカウンターはない。洞察薬は強化値＋4。5R目のためるは選択不可。

攻撃vs防御は防御側が常にダメージ0。防御値が厳密に上回る場合だけ、差分1〜2で1、3以上で差分のカウンター。同値は双方0。攻撃vs攻撃は各判定値を3で切捨て、最低1の相互ダメージ。防御同士は0。HP0で決着、同時0は引分。5R終了時の残HPが高い方が勝ち、同値は引分。能力Lvの自動判定加算なし。

持込枠は洞察Lv個、適格薬はLv3戦闘薬のみ。所持から隔離し、終了時に未使用分も消失。1R最大1個、効果はそのRだけ。秘匿勝者はアイテム強奪1個または翌日の採集／研究1AP命令を選択、第8日は強奪のみ。模擬戦ではFP・能力移転・通常決闘HO実績なし。公開決闘は全勝敗で結果確認→OK→公開復帰。人間参加の秘匿決闘は全勝敗で結果確認→OK→報酬処理。結果・各R・履歴は左＝仕掛けた魔女、右＝受けた魔女。

## HO・表示権限

22長期＋24日次HOの原文ID・名称・条件を `src/domain/goals.json` に保持。評価は `ho.ts`。窃盗条件の変換・旧得点条件の補完は decisions.md。日次は本人に未達成／達成見込み／達成確定と進捗を表示し、見込み自体では報酬を付与しない。日次は夜結果後、長期は達成履歴または第8日最終状態で判定。第8日の全判定は日次FP報酬前の同一状態を使い、その後FPを付与する。

通常画面に他者の所持、魔法、HO、夜行動を表示しない。秘匿決闘の解決済み手・出目・計算内訳は当事者だけに表示し、第三者には表示しない。取引は当事者のみ通知。終了後は配布済みHOと成否を開示し、相手所持や第三者の秘匿戦闘詳細は非開示。開発者モードとセーブJSONは全状態を含む。ローカルの試験環境であり、本番のサーバー権威・秘匿セキュリティは対象外。
