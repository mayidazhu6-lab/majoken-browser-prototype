# 日次まとめ・薬表示・画面遷移（2026-11-06）

## 作業範囲と調査

正式フォルダを使用。開始時はmain、未コミット変更なし、fetch後もorigin/mainとの差分0/0。NPC改修はPR #10でmain `589b68f` に統合済みだったため、その成果を保持し `feature/daily-summary-ui` を作成した。別クローン・worktree作成、旧ブランチの削除、Pages操作なし。今回のmainマージはユーザー確認後。

正式仕様browser-2.0.2のゲーム処理を基準とし、現在のv2.0.3のAI版分岐を維持。domain・stores・保存形式・AI・乱数処理のコードは変更しない。

持ち物のログには研究の消費素材や戦闘薬持込の数量などが不足する一方、初期設定・操作列・対応版エンジンから各操作の前後状態を復元できる。既存ログの種類・品名、取引内訳、調合レシピ、予約済み個体IDと突き合わせれば、公開/夜間両方の本人向け増減を表示できる。新たな履歴記録や必須保存フィールドは不要。FPは既存の本人向けfpログを使用。

## 変更

- タイトルのintro-notes上端の横線だけを除去。ボタン寸法・配置・文字揃えは維持。
- 秘匿行動を確定すると、既存のadvance処理へ進む。人間参加の決闘・報酬入力は維持し、NPC同士の決闘は既存の自動解決を使い、非当事者に戦闘画面を追加しない。現代版の秘匿決闘確認後の重複した汎用結果画面を省略。
- 課題判定前は既存の判定ボタン、確定後は同じ中央領域に1日のまとめを表示する。既存のpauseAtDawnを維持し、まとめ末尾の「次の日へ」でだけ翌日に進む。再開時に未処理操作を自動追加しない。
- まとめを左揃えの既存カードUIに統一。今日の課題名と成功/失敗、本人の卒業課題条件と既存graduationProgress、本人が閲覧可能な夜間記録、持ち物の原因別増減と品物別の日初/日末/差引、FP原因別増減と合計を表示。
- UI専用dailyReviewが隔離した状態で操作列を再生する。再生結果のゲーム状態・ログは実ゲームや保存枠へ書き戻さず、本人の持ち物と閲覧許可されたログから表示データだけを作る。実ゲームの乱数・報酬・効果は変更しない。
- 同じ品の購買での消費/獲得、同じ操作中の調合/強奪も個別に表示。薬の消費と、その後に繰り返し記録される効果適用を区別する。納品と模擬戦報酬も区別する。原因を確証できない差分は「内訳記録のない増減」と表示し、推測しない。保存状態との照合に失敗した場合は内訳を表示せず説明する。
- 研鑽は研究、豊穣は採集、交渉は購買の操作画面でのみ通常薬ボタンを表示。usable/canの既存制限を保持し、薬の消費と効果は変更しない。戦闘薬・自動発動薬の既存処理は維持。
