## 検出・修正と検証限界

初回ブラウザテストではVueのリアクティブオブジェクトをstructuredCloneできず開始不能になる問題を検出。Pinia境界でJSONデータへ変換して修正し、開始と8日間完走を再検証しました。統合試験でAIの複数取引ID重複を検出し、専用単調IDへ修正。画面確認でイベント確定後の納品数表示を修正しました。

HO成立例のユニット試験は評価器の条件網羅です。すべての例を合法な同一8日間の実操作として生成するものではありません。seed試遊とE2Eは別途実操作で検証しています。Safari/Firefox、モバイル実機、全46HO個別達成の探索、リモートCI、実Pages環境は未検証です。
