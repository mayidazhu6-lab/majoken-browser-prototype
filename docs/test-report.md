- 人間/AIの連続・最終Rためる拒否、幻惑後の実行手による制限、強化の1回消費、合法なAI手。既存の攻撃vsためる左右2〜6/高値・完全防御/カウンター・相互攻撃・薬資格/持込消失・最大5Rを維持。

- 専用6素材の研究、各1消費・1AP・基本+1、不足拒否、6万回抽選の偏り検査。購買部・薬・所有権・イベントの既存回帰も維持。
- 予約の第1巡1単位、取消による回復、第2巡の複数追加、先着枠、過剰/対象外/手番外拒否、数量選択のID解決、AP0時の魔女間取引申請。不正数量入力は表示と内部選択がずれないよう復元。
- 公開2巡終了でイベント自動確定し、結果確認前は後続操作を拒否。確認待ちと確認後の保存・再生、FPの再付与防止。崩壊直前の取引返答→自動判定→イベントOK→未判定HO終了表示もブラウザで確認。
- 公開決闘1AP、勝敗/引分でのFP、能力移転なし、降参品/双方FPなし、OK後の元手番復帰と第2巡の残AP。公開結果の確認待ち・降参待ちのブラウザ保存再開。
- 卒業者だけFP順、未卒業高FPの除外、同率1/1/3、日次HO数に左右されない首席。UIで未卒業の順位なし・卒業者0人を確認。
