## 重点的な進行回帰

- 日替わり席順、各日2巡と最終確認の全席1回を8日間検査。
- 1手番で2回目の1AP行動、手番外操作、最終確認前の公開終了を拒否。
- パスはAP非消費、枠の繰越なし。2AP決闘は2巡目をスキップ、被挑戦者のAP非消費。
- 取引返答・撤回、決闘応答・戦闘・報酬選択から元の順番に復帰。
- 同じ相手への申請は1巡2回、拒否・撤回も計数。次巡で再申請可能。
- AIの受諾・拒否・撤回後に同じ手番で再申請しない。未決時は進行停止、解除後は通常行動へ復帰。
- 仮納品・撤回を20往復連続しても手番・APを変えない。
- 強制命令2件を2巡へ分割。命令を残したパス・通常行動による回避を拒否。
- 秘伝レシピは翌公開終了後も保持、翌夜に作成でき、次の日には失効。
- 通常手番、最終納品確認、未決取引、戦闘途中、報酬待ち、夜錬金確定、夜明けで保存／再生を検査。ブラウザでも取引・戦闘・報酬・錬金のリロード復帰を確認。
