## 6. AI・ゲームバランス統計

### 再現条件と偏り

固定seed `qa-v21-0000`〜`qa-v21-0499`。seed番号 mod 3で協力・競争・研究に順次割り当て（167/167/166件）。人間席は全件 結界・3/3/3。既存 `simulationAction()` を土台に次を変更した隔離ハーネスを使用した。

1. 協力は既存の納品・必要研究・採集を維持し、夜は休息、錬金計画なし。
2. 競争は公開の合法AP行動枠で、2失敗未満なら相手公開水能力が最低の魔女へ決闘（同点は席順）。夜も同対象へ襲撃、相互襲撃翌夜制限中は警戒。2失敗時は基底のイベント協力へ戻る。
3. 研究は基底方針が採集/研究のとき、自己能力の低い属性順に合法研究を優先。追加/軽減素材は合法な候補を順に確認。無理なら基底行動。夜は休息。
4. 全方針で基底のイベント納品・模擬戦・取引受諾を維持。戦闘は水・利用可能ボーナス、持込薬なし。AI3人は製品実装のまま。

この人間席はHOに適応する熟練者ではなく、AIと同じ方策でもない。席/キャラクターの勝率を対称条件の公平性の証明に使わない。500件は100件を含み計600独立ゲームではない。3通しの通常終了seed選択は操作検証用で、500件の集計から失敗seedを除外していない。
